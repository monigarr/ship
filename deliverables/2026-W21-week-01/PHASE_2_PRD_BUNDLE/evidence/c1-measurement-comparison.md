## Methodology Delta

- Prior C1 artifacts focused on four broad counters (`any`, `as`, non-null, directives).
- New exact pass adds explicit subtype counters requested by PRD:
  - untyped function parameters
  - implicit-any-style missing return annotations
- New exact pass also emits per-package subtype breakdown and top-5 dense files with subtype-level counts and rationale.
- Type-coverage reports a typedness percentage and typed/total symbol counts; it does not directly emit all C1 violation subtype counters.

## Interpretation (Combined Targeting Priority)

Combined heuristic used: prioritize packages with the weakest type-coverage first, then break ties using C1 subtype volume/density.

1. **api** (target first): lowest type coverage (`89.32%`) plus high-risk C1 subtype volume (`any`, `as`, and non-null assertions are all concentrated here), making this the highest confidence remediation target.
2. **web** (target second): strong type coverage (`98.53%`) but the highest C1 subtype volume overall (especially untyped parameters), so this is the next best cleanup area after API risk is reduced.
3. **shared** (target last): perfect type coverage (`100.00%`) and near-zero C1 subtype findings, so this package is currently low priority.
